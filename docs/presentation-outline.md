# Project presentation outline

Use this outline to prepare the student's presentation. Add screenshots from the live Jira project and freshly executed app tests before presenting.

1. **Title and problem statement** — Smart Campus; explain the room-care and lost-item workflows.
2. **Project objective and scope** — show the two selected modules and intended users.
3. **Jira project management** — show project, requirements, epics, stories, backlog, sprint, assignee, and statuses.
4. **System design** — show the React frontend, Express API, and JSON-file persistence.
5. **Module 1: Cleaning Service** — submit a request, review the service desk, complete a ticket.
6. **Module 2: Lost & Found** — create a post, search, claim an item, and show the conversation.
7. **Testing and defects** — show freshly updated test cases, evidence, Jira bugs, fixes, and retest results.
8. **Source and conclusion** — show `frontend/` and `backend/`, explain limitations, summarize outcomes, and present the final working demo.
