# PBL final demonstration checklist

- [ ] Introduce **Smart Campus** and explain the shared-space and lost-item problem.
- [ ] Show the Jira project, requirements, epics, stories, tasks, sprint plan, assignee, and status flow.
- [ ] Sign in to the demo account and show the overview dashboard.
- [ ] Submit a cleaning request with building, floor, room, and issue; show the new ticket and notification confirmation.
- [ ] Mark a request complete and show its updated status and open-request count.
- [ ] Add a found item, optionally upload a JPEG/PNG, and show it on the community board.
- [ ] Search for an item and open a claim conversation; send a message and show the claimed state.
- [ ] Show the React source in `frontend/src/` and the Express API in `backend/`; describe the demo authentication and JSON-storage limits.
- [ ] Show fresh test-case results and associated Jira bugs, fixes, and retests. The supplied PASS results must not be presented as fresh runs of this demo.
- [ ] Close with the working app and project report/presentation material required by the course.
