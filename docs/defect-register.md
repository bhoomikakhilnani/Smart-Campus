## Jira bug fields

For each defect, record: summary, environment, affected module, preconditions, numbered reproduction steps, expected result, actual result, screenshot or recording, severity, priority, assignee, status, resolution, linked test case, fix version (if used), and retest result. Link the bug to the failed story and test case. Keep failed and retest evidence together.
